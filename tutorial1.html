Installing Unity Hub & VRC Creator Companion

(20 step tutorial, video coming soon)

Step 1

Navigate to https://vrchat.com/home/download and download the VRChat Creator Companion. If you haven't already, you'll need to sign up for a VRChat account.

Step 2

Next you will need to navigate to the Unity website https://unity.com/download and download the Unity Hub for your specified device. These tutorials are strictly following windows protocols currently.

Step 3

Once both of these are downloaded and you have both a Unity and a VRChat account, you're going to want to run and set up both programs. Once both are installed, you want to open up the VRChat Creator Companion and navigate to "Projects." Here we can create a new or import an old project. For the purposes of this tutorial, we will be creating one.

Step 4

Here you can name your world whatever you'd like and select where you want your project location to be on your computer.

Step 5

You'll notice the Create Project button is grayed out until you select "Unity 2022 World Project" from the top left.

Step 6

The project will now be created while we navigate elsewhere to grab the older unity editor version we need.

Step 7

Navigate to https://unity.com/releases/editor/archive to grab most recent compatible version of the unity editor that you need for VRChat, version 2022.3.22f1. See step 8 for more details here.

Step 8

You need to select Unity 2022, and LTS, as opposed to Unity 6 and supported. See Step 9 to continue.

Step 9

Scroll all the way down to 2022.3.22f1. You will absolutely notice the security alert warnings on all of these unity editor versions, and that's ok. VRChat creators can disregard the October 2025 Unity security warning in the Hub, as the recommended 2022.3.22f1 version remains safe and required for content creation. While a major Unity vulnerability affects standalone applications, VRChat is unaffected, and using newer, unapproved versions will prevent avatar/world uploading. Click install to the right of 2022.3.22f1

Step 10

You do not neccessarily have to always allow it, but at least for this time, we will click Open Unity Hub.

Step 11

Ensure you have the android build support options selected below. If you have used the desktop editor for MHW, chances are you already have VS Code. If you want to reinstall it keep this option checked as well. if not we will have to set VS Codes path later for Unity.

Step 12

You can monitor the progress of your editor installation from the downloads button in the top right area of the Unity Hub.

Step 13

When you see the green check mark next to each item in the downloads menu your installation is complete. Depending on your device specs this could take quite a while, and the editor will definitely take the longest.

Step 14

You can then confirm this installation in the Installs tab in the left sidebar menu. If you end up needing it for the VRChat creator companion or anything the Unity Editor path is there for you as well.

Step 15

Navigate back to the VRChat Creator companion. Are you still with me? If you are, I'm proud you haven given up on yourself or your creations yet. Under the Project's Unity tab, you'll notice a unity version number which should already be 2022.3.22f1. If not, you can select it by clicking it if it is different. You can either click Open Project to open your VRChat world in unity or Open with 2022.3.22f1, but we are not going to do that yet. Click Manage Project or close the Change Unity Version Menu and then click Manage Project, then see step 16.

Step 16

We are here to make standalone quest worlds am I right? We want to slowly bring our communities from Meta Horizon VR to our new VRChat experiences, to maintain those bonds we've created and the creations we've built. Notice how EasyQuestSwitch and VRChatWorld Toolkit are not preinstalled. Let's install both as we will need them. AudioLink is optional, and as I do not think I'll be showing you it you can choose if you wish to install this for later projects or perhaps future tutorials.

Step 17

They will have red removal icons when they are installed into your project properly. Now we can finally hit Open Project in the top right corner.

Step 18

Give your project some time to open successfully and load the Unity Editor, as well as install necessary packages. If for whatever reason you see a project errors popup you can click ignore as the errors are due to you not having the VRChat PC application installed on your device. (Again assume with this tutorial I am demonstrating windows installation instructions.)

Step 19

Click convert if you added AudioLink, and clear the console in the bottom left under the Project tab.

Step 20

And now you have Unity and the VRChat Creator companion installed and a blank VRChat world! Congrats!
